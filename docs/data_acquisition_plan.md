# 기존 데이터 우선 활용 및 선택적 추가 데이터 계획

## 0. 프로젝트에 이미 확보된 데이터

추가 수집 전에 아래 프로젝트 내부 데이터를 우선 사용한다.

- `data/processed/타팀원 db/cheonan_large_admin_call_rate_2019_2023.csv`: 2019~2023년 읍면동별 연간 응급관리 신고 건수와 인구 대비 신고율
- `data/processed/RL/region_features.csv`: 31개 읍면동별 `emergency_calls`, `calls_per_10000`, 응급발생위험 점수
- `data/processed/교통_스마트교차로_시간대별.csv`: 72개 교차로의 24시간 접근로별 교통량
- `data/processed/교통_도로구간_소통통계.csv`: 168개 도로구간의 평균속도, 교통량, 대표 혼잡시간
- `data/mapping/도로구간_행정동매핑.csv`, `data/mapping/스마트교차로_행정동매핑.csv`: 도로·교차로의 공간 매핑 근거

증차 동적 배차의 기본 수요는 읍면동별 연간 응급관리 신고 건수로 생성한다. 현재 보유 데이터에는 시간대별 119 신고 건수가 없으므로, 시간대 수요를 교통량으로 대체하지 않고 우선 균등 도착 시나리오를 사용한다.

## 1. 기존센터 증차 시뮬레이션

### 선택적 보강: 소방청 구급정보서비스

- 포털: https://www.data.go.kr/data/15099423/openapi.do
- 제공 단위: 시도본부, 출동소방서, 신고년월, 신고시
- 핵심 필터: `충청남도소방본부`, `천안동남소방서`, `천안서북소방서`
- 활용: 현재 균등 도착 시나리오를 실제 월·시간대별 신고 비중으로 고도화
- 필요 사항: 공공데이터포털 활용신청 후 서비스키 발급

이 API에는 출동소방서·신고년월·신고시·구급사고유형 등이 포함된다. 개인 단위 원시 기록을 저장하지 않고, 월·시간대 집계값만 프로젝트에 사용한다.

### 선택적 보강: 소방청 본부별 구급활동정보

- 포털: https://www.data.go.kr/data/15080046/fileData.do
- 범위: 2020년 1월~2024년 12월, 시도별 월별 출동·이송·이송환자 수
- 활용: 충남 월별 총수요, 계절성, 이송률을 보정하고 API 집계값의 합계와 교차 검증

### 필요 시 정보공개청구

공개 API가 센터별 시간대 수요를 충분히 제공하지 않으면, 천안동남·서북소방서 관할의 월별·시간대별 구급 출동 건수 집계를 요청한다. 개인식별정보·주소·환자정보는 요청하지 않는다.

## 2. 도로 개선 시뮬레이션

### 선택적 보강: 국가교통정보센터 교통소통정보

- 포털: https://www.its.go.kr/opendata/intro
- 표준 Node/Link 기반 속성: `linkId`, `speed`, `travelTime`, 생성시각
- 활용: 현재 도로구간 평균속도·대표 혼잡시간을 표준 `LINK_ID` 단위 실제 속도로 고도화
- 필요 사항: 국가교통정보센터 Open API 인증키 신청

도로 개선 후보는 현재 확보된 도로구간 평균속도·교통량·대표 혼잡시간으로 우선 선정한다. 다만 Node/Link 단위 실제 속도는 추가 데이터가 있어야 직접 결합할 수 있다.

### 보조: 한국도로공사 VDS·콘존 데이터

- VDS 지점 교통량·속도·지정체 분석: https://www.data.go.kr/data/15062124/fileData.do
- 콘존·차로별 교통 소통 데이터(5분): https://www.data.go.kr/data/15103518/fileData.do

고속도로 및 주요 진입축의 시간대별 혼잡 보조지표로만 사용한다. 천안 도심 일반도로 전체를 대표하지 않으므로 국가교통정보센터 소통정보의 대체재로 사용하지 않는다.

## 4. 수집 후 검증 순서

1. API 응답의 기관·기간·시간대 누락 확인
2. 월별 출동 합계가 본부별 구급활동정보와 일관되는지 확인
3. 도로 소통 `linkId`가 현 Node/Link `LINK_ID`와 얼마나 매칭되는지 확인
4. 속도·통행시간 결측 및 이상치 제거 기준 기록
5. 수요·교통 데이터를 적용한 시뮬레이션을 기존 baseline과 별도 결과 폴더에서 재평가
